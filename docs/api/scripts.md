# scripts

`z.scripts` управляет загрузкой скриптов из Lua и даёт доступ к папке скриптов.
Список по-прежнему хранится только в активном конфиге; автоматического
сканирования папки нет.

## Редактор в меню

Во вкладке **Lua** → **Scripts** есть кнопка **new** и кнопка **edit** в каждой
строке списка. Они открывают полноэкранный редактор с подсветкой синтаксиса:

- **new** создаёт новый файл из шаблона; имя можно изменить до сохранения;
- **edit** загружает содержимое существующего скрипта;
- **save** записывает файл, **save + reload** дополнительно перезагружает все
  скрипты;
- **discard** закрывает редактор без сохранения;
- `Ctrl+S` — сохранить, `Ctrl+Enter` — сохранить и перезагрузить.

Новый файл при сохранении добавляется в `lua.script list` и включается. Путь
проверяется теми же правилами, что и для списка: только `.lua`, только внутри
папки скриптов. Редактор сохраняет текст в UTF-8 с LF и пробелами: CRLF
нормализуется, BOM убирается, табы заменяются на четыре пробела.

## z.scripts.reload()

```lua
z.scripts.reload()
```

Ставит перезагрузку в очередь. Она выполняется не внутри текущего callback, а
на ближайшей безопасной границе: в `on_create_move`, `on_present` или `on_ui`,
когда менеджер уже не держит активный Lua-вызов.

Это важно: `reload()` не закрывает state прямо посреди функции. Код после
вызова в том же обработчике успеет выполниться, а затем все состояния будут
выгружены и загружены заново. У каждого скрипта вызывается `shutdown`, кроме
упавших скриптов.

```lua
z.events.ui:add(function()
    z.ui.begin_window("script control", 40, 40, 260, 120)
    if z.ui.button("reload all", 120, 24) then
        z.scripts.reload()
    end
    z.ui.end_window()
end)
```

## z.scripts.directory()

```lua
local path = z.scripts.directory()
z.log(path)
```

Возвращает абсолютный путь папки скриптов строкой. Это путь, от которого
разрешаются относительные записи `lua.script list`.

## z.scripts.open_directory()

```lua
z.scripts.open_directory()
```

Открывает папку скриптов в Проводнике. Возвращает `nil`. Вызов выполняется
синхронно и не проверяет, что Проводник действительно открылся.

## Список скриптов через настройки

Список — custom-поле `lua.script list`. Его можно прочитать и заменить как
JSON-совместимую таблицу:

```lua
local list = z.settings.get("lua", "script list")
for _, entry in ipairs(list) do
    z.log(entry.path, entry.enabled)
end

z.settings.set("lua", "script list", {
    { path = "bhop.lua", enabled = true },
    { path = "overlay.lua", enabled = false },
})
-- reload уже поставлен в очередь автоматически
```

Запись `lua.script list` сама запрашивает перезагрузку. Для глобальных
переключателей используй primitive-настройки:

```lua
z.settings.set("lua", "lua scripts", true)
z.settings.set("lua", "lua ffi", false)
```

Смена `lua scripts` или `lua ffi` перезагружает рантайм на ближайшем
`on_present`, потому что меняется набор открытых библиотек.

## Ограничения

- `reload()` не принимает путь и не загружает отдельный файл. Он перезагружает
  весь список активного конфига.
- Нельзя вызвать `reload()` из `shutdown`: state и так закрывается.
- Скрипт, который постоянно вызывает `reload()` из `create_move`, будет
  перезагружаться почти каждый тик. Не делай так.
- Пути проверяются менеджером: только `.lua`, только внутри папки скриптов,
  без выхода через `..`/symlink.
- `directory()` и `open_directory()` не дают доступа к чужим файлам; это только
  путь папки скриптов.
